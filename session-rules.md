# Session Hygiene Rules

1. Keep one task per session.
   - Prevents: Drift

2. Avoid adding unrelated files or projects to context.
   - Prevents: Over-reach

3. Record important decisions when they change.
   - Prevents: Lost constraints

4. Use compact when the session is long but the task is still valid.
   - Prevents: Stale picture

5. Start a fresh session when the agent contradicts itself twice or ignores a constraint.
   - Prevents: Contradiction

## Restart Trigger

Start a fresh session when the agent contradicts itself twice or ignores an
important constraint, instead of trying to rescue the confused session.
